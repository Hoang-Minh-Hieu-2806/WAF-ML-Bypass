### R7 historical `executed` field note

The old PL2 evidence row for `xss-de-mal-001` records HTTP 403 and `execution_status=blocked`, but also `executed=true`. The screenshot is the generic nginx 403 page; its title changed from the blank browser page and triggered a false positive in the old generic-title fallback. The canonical status is `blocked`, so the case was not counted as executed or as a bypass. Commit `db15e8a` changes the oracle to require the expected title marker or a dialog on a 2xx response; four unit tests cover blocked pages and unmarked title changes. The historical raw JSON is preserved unchanged. The PL1 row remains HTTP 200, unreflected, `not_executed`.
